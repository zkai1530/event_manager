# Eventify - *Event Management Website*
Eventify is a web-based platform that allows users to explore and join events, purchase tickets, and receive QR codes for check-in. Event organizers can create and manage their events (including schedules, seat map, tickets and promotions).
## ✨ Feature
- User: Register/Login (JWT & Google), browse events, buy tickets, receive QR for check-in.
- Organizer: Create & manage events (seat map, tickets, schedules, promotions, …), check-in participants, view statistics.
- Admin: View all statistics for system, view events, manage users, disbure payments.
- Authentication: Secure login & authorization with JWT.
- Payment: Bank transfer via PayOS.
## 🛠️ Technologies Used
- Java, Spring Boot  
- MySQL  
- ReactJS, TailwindCSS  
- Deployment: Netlify + Render
